# Sistema de Ponto Web – PlayShop

Sistema web para controle de ponto de funcionários, com painel administrativo, auditoria de registros e geração de relatórios mensais.

---

## 🌐 Sistema Online

O sistema está disponível  no link abaixo:

🔗 https://sistema-de-ponto-web-playshop-production.up.railway.app

---

## 🛠 Tecnologias Utilizadas

Backend:
- Python
- Flask
- Flask-Login
- Flask-Migrate
- SQLAlchemy

Banco de Dados:
- PostgreSQL

Infraestrutura / Deploy:
- Railway
- Gunicorn

Versionamento:
- Git
- GitHub

---

## 📌 Funcionalidades do Sistema

- Autenticação de usuários
- Painel administrativo
- Cadastro e gerenciamento de funcionários
- Registro de ponto (entrada e saída)
- Auditoria de alterações
- Relatório mensal de horas

---

## 🚀 Deploy

O projeto foi publicado utilizando:

- **Railway** para hospedagem da aplicação
- **PostgreSQL Railway** como banco de dados
- **GitHub** para versionamento do código
